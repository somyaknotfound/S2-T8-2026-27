# Stage 4 — does the delay-aware rule settle after warm-up?

Load sweep, mixed users, 5 runs per point. Each run has 2000 requests; the first 500 are warm-up. The measured part is split into thirds. Δ is the last third minus the first, paired over runs (95% CI). A learner still improving would show a negative Δ whose CI excludes 0; the oracle (s_min in the Interest) does not learn, so its Δ shows the run-to-run noise.
